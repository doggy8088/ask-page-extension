核心結論

一句話

詢問模式只讀頁面並回答，代理模式才帶著頁面工具去讀、點、填、改。

切換方式
對話框輸入 /agent，或點模式切換按鈕
儲存位置
chrome.storage.local 的 HTML_MODE_ENABLED
作用範圍
目前頁面的 content script
自訂指令
設定頁可指定每個指令用詢問或代理模式

送出流程的兩條分支

系統提示詞也分成兩條分支，明令模型在詢問模式不得使用頁面工具。

D

頁面上下文怎麼產生

  • 快照 Token 預算預設 8000，設定頁可調整範圍 2000 到 60000。
  • 代理模式可改用完整過濾 HTML，Token 用量高，相容性較好。
  • 選取文字在兩種模式都是主要焦點，代理模式會優先保留選取範圍。
E

代理模式的工具階梯

  • 工具階梯由便宜到昂貴，模型應先讀後寫。
  • 工具回傳內容一律截斷在 6000 字元，超過會附上提示。
  • 呼叫輪數上限預設 50，達到上限會中止任務。
F

注意

詢問模式同樣能用 Google Search、Anthropic 原生 Web Search 與 Ollama 網頁搜尋，因為這些搜尋工具不屬於頁面工具。Anthropic 的搜尋由伺服器執行，回覆會附上 citations，AskPage 會在末尾列出參考來源。

H

怎麼選與怎麼用

選擇原則

先用詢問模式理解頁面，需要改頁面或填表時再切到代理模式。

  1. 用詢問模式摘要、翻譯、比對頁面內容。
  2. 需要動手前先輸入 /agent 切換模式。
  3. 說明目標、範圍與驗收條件，一次一項。
  4. 代理模式完成後檢查頁面結果。
  5. 需要重來時用 /clear 清掉對話與工具輪次。
  • 自訂指令可在設定頁指定回應模式，執行時自動切換。
  • 切回詢問模式會清除尚未送出的附圖。
  • 代理模式的介面訊息仍寫「頁面 HTML」，實際格式以設定頁為準。
